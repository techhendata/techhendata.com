# TechHen Data Solutions Website

This repository contains the 100% free, high-performance static website for **TechHen Data Solutions LLC**.

## 📁 Repository Structure
* `index.html` - The production-ready responsive single-page landing code.
* `logo.png` - The TechHen logo used in the site header.

## 🚀 Instant Deployment Instructions
To host this site completely for free on your custom domain using Netlify or Vercel:
1. Drag and drop this repository folder directly into your dashboard.
2. Link your custom Namecheap domain inside your deployment settings.
